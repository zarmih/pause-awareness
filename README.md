# Pause Awareness

**Metacognition trainer: building an awareness layer over ancient instincts in the modern technological world.**

We are still hunter-gatherers biologically. Our dopamine systems, social instincts, and attention mechanisms evolved for scarce resources and small groups. Modern apps exploit them. This project is a practical protocol + app concept to insert a thin layer of metacognition between stimulus and response.

## Core Idea

- Instincts are not the enemy. They are fuel.
- The goal is not suppression, but **interception**: notice the program launching → insert a pause → choose.
- Awareness scoring makes the process measurable.

## 7-Day Protocol

See [PROTOCOL.md](PROTOCOL.md) for the full strict version with awareness scoring.

### Quick Rules
- No phone for first 15 minutes after waking.
- Every social media / feed open requires a 10-second micro-pause + "What am I seeking?" + awareness score (1–10).
- Max 3×15 min social media sessions per day.
- One 45-minute single-task focus block daily (phone in another room).
- Evening review with awareness data.

## App Concept

See [APP_SPEC.md](APP_SPEC.md) for screens, flows, and data model.

Key features:
- Full-screen micro-pause overlay with awareness slider + trigger question.
- Morning check-in.
- Evening review with averages and patterns.
- Dashboard showing awareness trend vs. impulse control.

"Man of the future" is not someone who deleted their ancient programs. It is someone who can observe them in real time and choose.
